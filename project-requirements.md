**Project Goal & Architecture Rule**
The core logic relies on "Image Compositing": mapping individual letter images onto a base background image using specific X, Y coordinates based on user input.
To save storage, the system MUST NOT save the final generated image to the disk. Final images are rendered entirely in RAM (on-the-fly) when a user previews or downloads them. The database only stores the JSON input data. To ensure smooth local development and rendering on machines with standard specs (e.g., i3 processors with 12GB RAM), the image compositing logic must be strictly optimized for memory efficiency—ensure image instances are immediately destroyed/cleared from RAM after being streamed as a response.
